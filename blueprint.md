# **App Name**: ShiftSpace

## Core Features:

- User Authentication: Secure user accounts with multi-device access and data synchronization.
- Script Gallery: Gallery view of user-created scripts with customizable templates. Users will have a default, 'original template' they can modify, and also create new templates.
- Waiting Room: A personalized space similar to Notion, with a gallery view for places.
- Information Hub: Collapsible pages for personal information, safewords, definitions, and rules.
- Integrated Journal: Notion-like journal with shortcuts to Pinterest, Notion, YouTube, and other platforms.
- Media Integration: Embed images, videos, and GIFs into scripts and journal entries.
- Spotify playlist embed: Tool for the LLM to insert links that embed and play music from Spotify within scripts.

## Style Guidelines:

- Primary color: Soft lavender (#D0B8FF) for a dreamy and imaginative feel.
- Background color: Very light gray (#F5F5F5), close in hue to the primary, for a clean, spacious feel.
- Accent color: Muted rose (#FFB8D0) for highlighting important elements.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable experience.
- Minimalist icons for navigation and actions.
- Notion-inspired visual design for a familiar user experience.
- Subtle transitions and animations for a smooth and engaging user experience.
